# formal.org Verification Diagrams

This collection includes educational diagrams and flowcharts for learning hardware formal verification.

## About formal.org

formal.org is a browser-based educational platform for learning hardware formal verification using SystemVerilog Assertions (SVA). We provide structured, hands-on learning resources for graduate students and engineers entering the formal verification field.

Visit [formal.org](https://formal.org/) to explore the complete platform.

## What Are These Diagrams For?

These diagrams visually explain key formal verification concepts, including:

- **Proof Methodology** - Bounded and unbounded model checking, induction, and convergence
- **SystemVerilog Assertions** - Immediate, concurrent, safety, and liveness properties
- **Proof Engines** - SAT, SMT, and BDD-based solvers and when to use each
- **Cover Properties** - Reachability checking and stimulus-free exploration
- **Abstraction Techniques** - Cutpoints, black-boxing, and data abstraction
- **Protocol Verification** - Handshaking, arbitration, and interface assumptions
- **Counterexample Analysis** - Reading traces and debugging failing proofs
